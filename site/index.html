What the exporter does first.

  1. Ask the mill for its report.Request the CBAM verification report on 2026 production. Any verified figure below tCO₂e/t beats the marked-up default from 2028.
  2. Line up a verifier now.The Commission expects first verification work in early 2027, the first visit has to be physical, and Europe's fastener distributors expect a bottleneck.
  3. Write the saving into contracts.The importer pays CBAM and the exporter pays for verification, so the split has to be agreed.
  4. Buy as a cluster.One small exporter has little pull on a mill. A cluster's rod order can ask for the report and share a verifier.
